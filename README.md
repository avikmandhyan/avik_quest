## AvikQuest — Life RPG Dashboard -macOS App
A gamified goal tracker built to manage career, fitness, finance 
and personal development goals through an RPG interface.

**Built with:** HTML, CSS, JavaScript  
**Data:** localStorage for persistent progress  
**Why I built it:** Needed a system to stay accountable to 
long-term goals across multiple life areas.

### Install in 3 steps. Double-click forever after.

---

## Install

1. **Unzip** this folder somewhere (Desktop is fine)
2. **Open Terminal** — press `Cmd + Space`, type `Terminal`, press Enter
3. **Paste this one command** and press Enter:

```
bash ~/Desktop/AvikQuest_Installer/install.sh
```

*(If you put the folder somewhere else, adjust the path accordingly)*

That's it. Takes about 2 minutes. After that:

- Find **AvikQuest** in your Applications folder
- Double-click to open — no Terminal needed, ever again
- Add it to your Dock by right-clicking → Options → Keep in Dock

---

## If macOS shows a security warning

Go to: **System Settings → Privacy & Security → scroll down → click "Open Anyway"**

This happens because the app isn't from the App Store. It's safe — it's just your own code running locally.
